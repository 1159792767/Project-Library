# 程序内更新与回退演示
下载 Releases 中 Demo.App-1.2.0-win-x64.zip，完整解压并打开 EXE。
点击“检查更新 / 版本管理与回退”，升级到 1.2.1。再次打开该窗口，选择 1.2.0 并回退。计算结果由 10 变成 30，再变回 10。
回退需要原版本目录保留；只切换程序，不回退数据库。第一次直接下载 1.2.1 不会自动获得历史版本。
组件由公共库 updater 目录维护，以 Team.DesktopUpdater.1159792767 NuGet 包引用。当前支持 .NET 10 Windows，附带 WinForms 界面；并非给任意软件安装即可生效的通用 MSI。
独立目录安装；原快捷方式不会自动切换。主窗口显示当前目录。手动回退，不包含启动失败自动回退。
旧版本 1.1.x 尚未集成历史记录，请从 1.2.0 开始本轮演示。
